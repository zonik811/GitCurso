No todo el mundo quiere (o necesita) memorizar comandos. **GitHub Desktop** es la aplicación oficial y gratuita de GitHub para usar Git con interfaz gráfica. Es ideal para empezar y perfecta para tareas visuales como revisar diffs o resolver conflictos.

## ¿Qué es GitHub Desktop?

Es un **cliente de Git con interfaz gráfica**. Por debajo ejecuta los mismos comandos que aprendiste, pero te los presenta con botones, listas y vistas de diferencias.

```text
Tú → GitHub Desktop → comandos de Git → repositorio
```

Ventajas:

- No memorizas comandos.
- Los **diffs** se ven con colores, lado a lado.
- Resolver conflictos es mucho más claro.
- Gestiona tu autenticación con GitHub automáticamente.

Limitaciones:

- No cubre operaciones avanzadas (rebase interactivo, reflog, etc.).
- Algunos flujos finos requieren la terminal.

<Callout type="info">
  Lo mejor de ambos mundos: usa Desktop para el día a día y la terminal cuando necesites potencia. No es "una cosa o la otra".
</Callout>

## Instalar GitHub Desktop

Descárgala desde [desktop.github.com](https://desktop.github.com). Está disponible para **Windows** y **macOS** (no hay versión oficial para Linux).

También puedes instalarla con gestores de paquetes:

```powershell
winget install GitHub.GitHubDesktop
```

```bash
brew install --cask github
```

## Iniciar sesión

Al abrirla por primera vez:

1. Pulsa **Sign in to GitHub.com**.
2. Autoriza la aplicación en el navegador.
3. Listo: la app ya tiene acceso a tu cuenta.

Si prefieres no iniciar sesión, puedes configurar tu nombre y correo manualmente en **File → Options → Git**, pero conectar la cuenta es lo recomendado.

## Conociendo la interfaz

```text
┌─────────────────────────────────────────────────────────┐
│  Current Repository ▼   Current Branch ▼   [Fetch/Pull]  │  ← Barra superior
├───────────────────┬─────────────────────────────────────┤
│  Changes          │                                     │
│  ☑ archivo1.js    │      DIFF DEL ARCHIVO               │
│  ☑ estilos.css    │      (líneas rojas = borradas,      │
│                   │       verdes = añadidas)            │
│  [ Summary ]      │                                     │
│  [ Description ]  │                                     │
│  [Commit to main] │                                     │
├───────────────────┴─────────────────────────────────────┤
│  History  |  Changes                                     │  ← Pestañas
└─────────────────────────────────────────────────────────┘
```

Elementos clave:

- **Current Repository**: el repo en el que estás trabajando.
- **Current Branch**: la rama actual.
- **Changes**: los archivos modificados, con casillas para elegir qué entra en el commit.
- **Diff**: la vista de diferencias del archivo seleccionado.
- **Summary / Description**: el mensaje de commit.
- **Commit to …**: el botón para confirmar.
- **History**: el historial de commits de la rama.
- **Fetch origin / Pull / Push**: sincronización con GitHub.

## Añadir un repositorio

Tienes tres formas:

1. **Clone a repository**: clonar desde GitHub (tus repos o cualquier URL).
2. **Create a new repository**: crear uno nuevo local (y opcionalmente publicarlo).
3. **Add an existing repository**: abrir una carpeta que ya es un repo Git.

Las veremos en la próxima lección.

## Atajos útiles

| Atajo | Acción |
| --- | --- |
| `Ctrl/Cmd + Enter` | Hacer commit |
| `Ctrl/Cmd + P` | Push |
| `Ctrl/Cmd + Shift + P` | Pull |
| `Ctrl/Cmd + R` | Ver el repositorio en GitHub |
| `Ctrl/Cmd + N` | Nuevo repositorio |
